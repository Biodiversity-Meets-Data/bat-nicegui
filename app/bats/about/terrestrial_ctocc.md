# Camera-Trap Occupancy Trends

Estimate annual site-use trends for one target species from repeated Camtrap DP
monitoring data while accounting for imperfect detection.

## Typical Use Cases

- Assess multi-year changes in camera-trap site use.
- Review monitoring coverage and model diagnostics.
- Compare initial and final site-use probabilities.

The workflow does not estimate population abundance or spatially varying trends.
