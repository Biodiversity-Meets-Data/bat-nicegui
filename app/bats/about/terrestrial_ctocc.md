### About this Tool

The Occupancy Trend Analysis Tool estimates temporal changes in wildlife site use from standardized Camtrap DP datasets. It applies a non-spatial, multi-season occupancy model to repeated camera-trap observations, accounting for imperfect detection to estimate annual site-use probabilities and trends.

### Features

- **Detection-Corrected Site Use:** Estimate the probability that a species uses a monitored grid cell while accounting for imperfect detection.

- **Annual Occupancy Estimates:** Visualize estimated site-use probabilities across monitoring years, including uncertainty intervals.

- **Occupancy Trends:** Quantify overall and annualized relative changes in estimated site use, including posterior uncertainty and probabilities of increase or decline.

- **Automatic Grid Selection:** Select a suitable spatial grid resolution based on camera-trap monitoring coverage.

- **Monitoring Coverage:** Examine annual survey effort, monitored grid cells, and site-weeks with species detections.

- **Model Diagnostics:** Review convergence statistics and other indicators of model and data quality.

### Results

The tool produces an interactive dashboard with annual site-use estimates, relative changes, posterior distributions, and monitoring diagnostics.

Positive or negative trends indicate increasing or decreasing estimated site use, respectively, rather than changes in population abundance. Credible intervals describe uncertainty around estimates.

If model convergence is unsuccessful, available estimates remain visible with an explicit warning and should be interpreted with care.
